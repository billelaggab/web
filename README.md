# منظومة إدارة جهات الاتصال والاستخبارات (I.C.I.M.S)

نظام **محلي معزول (Air-gap)** لإدارة ملفات الأشخاص، قنوات الاتصال، الملاحظات الاستخبارية،
شبكة العلاقات والأدلة الرقمية — مصمّم للصحفيين الاستقصائيين، بواجهة **عربية RTL كاملة**
ووضع ليلي، وبدون أي اتصال بأي خدمة خارجية.

> كل الأسماء والبيانات التجريبية خيالية بالكامل.

---

## 1) ما الذي يعمل الآن في هذا المستودع؟

تطبيق ويب كامل (Fullstack) يعمل بنقرة واحدة داخل هذا المشروع:

| الطبقة | التنفيذ الجاهز هنا | نظيره في المواصفات الأصلية |
| --- | --- | --- |
| الواجهة | **React 19 + Bootstrap 5 RTL** (محمّلة محلياً من `node_modules`) عبر Next.js App Router | React + Vite + `react-bootstrap` |
| الواجهة الخلفية | **Route Handlers** (TypeScript، تحقق صارم كنظير Pydantic) | FastAPI |
| قاعدة البيانات | **PostgreSQL 16 + Drizzle ORM** | PostgreSQL 15 + SQLAlchemy |
| محرك البحث | فهرس PostgreSQL محلي مع تطبيع عربي + مطابقة ضبابية، **وطبقة Meilisearch اختيارية** تُفعَّل بمتغير بيئة | Meilisearch |
| التصدير/الطباعة | صفحة ملف جنائي قابلة للطباعة + نقطة نهاية HTML مستقلة جاهزة لـ WeasyPrint | WeasyPrint / Puppeteer |
| التنسيق | Docker + Docker Compose + Nginx + شبكات معزولة | نفسه |

مرجع **FastAPI/SQLAlchemy/Meilisearch/WeasyPrint** الكامل موجود في `reference/fastapi/`
لتشغيله كخدمة بايثون موازية أو استبدال طبقة الويب بالكامل.

## 2) التشغيل السريع (بدون Docker)

```bash
cp .env.example .env          # ثم عدّل DATABASE_URL / APP_SECRET
npm install
npx drizzle-kit push          # إنشاء الجداول
npm run build && npm start    # أو: npm run dev
# إدخال بيانات تجريبية (إن كانت القاعدة فارغة):
curl -X POST http://localhost:3000/api/seed
```

## 3) التشغيل عبر Docker (الإنتاج على Ubuntu)

```bash
cp .env.example .env
docker compose up -d --build
docker compose run --rm migrate     # تطبيق المخطط على قاعدة البيانات
curl -s http://127.0.0.1:8080/api/health | head
```

التفاصيل الكاملة (النسخ الاحتياطي، النقل إلى جهاز معزول، تدقيق الأمان):
`docs/DEPLOYMENT.md`.

## 4) الوحدات الرئيسية

- **الملف الأساسي (Person):** UUID، الاسم، الأسماء المستعارة، صورة الملف، تاريخ الميلاد،
  الجنسية، النشاط/الغطاء، العنوان، موثوقية 1–5، حساسية (عام/سري/سري للغاية).
- **قنوات الاتصال:** أرقام E.164 + تصنيف (شخصي/عمل/مؤقت) + أعلام التطبيقات (واتساب/سيجنال/تيليجرام)
  وملاحظات المشغّل — بريد (أساسي/مُسرَّب/آمن) مع بلوك PGP — حسابات التواصل.
- **الملاحظات الاستخبارية:** عنوان، محتوى Markdown آمن، تصنيف (اجتماع/مالي/تحقق خلفي/تسريب)،
  تاريخ الحدث، تاريخ التدوين، علم «سري» يفرض تأكيداً منفصلاً للعرض والطباعة.
- **شبكة العلاقات:** علاقات ذاتية المرجع (محامٍ، شريك تجاري، قريب، شريك في فعل، خصم، مُبلِّغ)
  مع درجة ثقة (مؤكدة/مشتبه بها) وسياق — ورسم بياني تفاعلي.
- **المستندات والوسائط:** رفع جماعي بالسحب والإفلات، أسماء تخزين UUID معقّمة، قائمة بيضاء
  للامتدادات وMIME، بصمة SHA-256 لكل ملف، تنزيل عبر رمز HMAC مؤقت، معرض صور Lightbox،
  معاينة PDF داخل المتصفح.
- **البحث الموحّد:** فوري عبر الأسماء/الأرقام/البريد/الحسابات/محتوى الملاحظات/بيانات المستندات،
  مع تطبيع عربي (أ/ا/إ/آ، ة/ه، ي/ى، إزالة التشكيل) وتحمّل الأخطاء المطبعية.
- **الملف الجنائي القابل للطباعة:** ترويسة مصنّفة + علامة مائية + بطاقات اتصال + سجل زمني +
  دليل علاقات + فهرس أدلة، مع مرشّح تعقيم (استثناء السري / استثناء الوسائط / كامل).
- **سجل التدقيق:** كل عملية إنشاء/تحديث/حذف/رفع تُسجَّل مع الوقت والفاعل (سلسلة العهدة).

## 5) واجهات REST

| الطريقة | المسار | الوظيفة |
| --- | --- | --- |
| `GET` | `/api/health` | فحص صحة التطبيق وقاعدة البيانات ومجلد الوسائط ومحرّك البحث |
| `GET`/`POST` | `/api/persons` | قائمة الملفات (تصفية) / إنشاء ملف مع قنوات الاتصال والملاحظات |
| `GET`/`PATCH`/`DELETE` | `/api/persons/:id` | الملف الكامل (بأي نمط تعقيم) / تحديث / حذف |
| `POST`/`PATCH`/`DELETE` | `/api/records` و `/api/records/:kind/:id` | إنشاء/تحديث/حذف السجلات الفرعية (`phone`/`email`/`social`/`note`/`relationship`) |
| `GET`/`POST` | `/api/documents` | قائمة مستندات ملف / رفع جماعي (multipart) |
| `PATCH`/`DELETE` | `/api/documents/:id` | تحديث الوصف أو تعيين صورة الملف / حذف |
| `GET` | `/api/documents/:id/file?token=…` | بث الملف عبر رمز موقّع (`&download=1` للتنزيل) |
| `GET` | `/api/search?q=…` | البحث الموحّد الفوري |
| `POST` | `/api/search/reindex` | إعادة بناء الفهرس + مزامنة Meilisearch |
| `GET` | `/api/dossier/:id?profile=…&format=html\|json` | الملف الجنائي (HTML للطباعة/PDF أو JSON) |
| `POST` | `/api/seed` | إدخال بيانات تجريبية |

## 6) الأمان

- **عزل الشبكة:** لا CDN، لا خطوط خارجية، لا تحليلات. Bootstrap RTL وBootstrap Icons تُحمَّل
  من `node_modules`، والخطوط (Tajawal/Cairo) من `public/fonts`.
- **Path Traversal:** أسماء التخزين تُولَّد كـ UUID صارم مع قائمة امتدادات بيضاء، وكل مسار
  يُتحقق منه أن يقع داخل `MEDIA_DIR`.
- **SQL Injection:** كل الاستعلامات عبر Drizzle ORM بمعاملات مُهيّأة.
- **XSS:** عارض Markdown يهرّب كل HTML قبل تطبيق أي تنسيق، ولا يُسمح إلا بروابط `http(s)`/`mailto`.
- **سيادة البيانات:** الوسائط خارج المجلد العام، ولا تُبث إلا عبر رموز HMAC صلاحيتها 15 دقيقة.
